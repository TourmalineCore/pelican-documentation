# Прикрепление VK видео к новостям

# Статус
Предложенный

## Контекст
Необходимо найти способ прикрепления VK видео в виде плеера в новости. В данный момент можно только прикрепить ссылку на видео в тексте или загрузить файл видео в CMS.

## Технические ограничения
Прикрепить VK видео можно лишь через iframe, так как использование тега video невозможно из-за того, что видео нельзя воспроизвести по прямой ссылке.
При этом работа видео полностью зависит от VK, а не от нас.

## Решение (Вставка ссылки на видео и обработка ссылки на стороне CMS)
Контент-менеджер вставляет ссылку на видео через CKEditor (либо напрямую в текст, либо через специальную кнопку для вставки медиа). Со стороны разработки необходимо настроить плагин на стороне CMS для работы с ссылками VK и подготовки разметки с iframe для возврата на UI.

Использование iframe для встраивания видео VK является безопасным, поскольку:
- Мы контролируем генерацию разметки: iframe создается по строгому шаблону, а не на основе пользовательского ввода. Контент-менеджер вставляет только ссылку, которая проходит валидацию (используется только доверенный домен VK).
- Использование sandbox-атрибута с параметрами (allow-scripts и allow-same-origin): включаем только самое необходимое для работы плеера, все остальное ограничиваем.
- На стороне UI есть настройки CSP, которые разрешают загрузку данных только с разрешенных доверенных источников.

## Плюсы
- Простое добавление видео со стороны контент-менеджера.
- Безопасно.
- Старые новости не сломаются.

## Минусы
- При изменении домена VK потребуется обновить конфигурацию в коде.

## Альтернативы
## Вставка ссылки на видео и обработка ссылки на стороне UI
В этом случае контент-менеджеру нужно только вставить ссылку на видео, которое он хочет прикрепить. Со стороны разработки необходимо настроить парсинг строк на UI и определять ссылки на VK видео, оборачивая их в iframe для отображения. По сравнению с выбранным решением этот вариант затрагивает старые новости и может их сломать, если там уже ранее была вставлена ссылка на VK видео.

## Плюсы
- Простое добавление видео со стороны контент-менеджера.
- Безопасно.

## Минусы
- При изменении домена VK потребуется обновить конфигурацию в коде.
- Старые новости, в которых уже были вставлены ссылки на видео, могут некорректно отображаться.

## Экспортировать iframe код видео из VKvideo
В этом случае контент-менеджеру нужно перейти на видео, которое он хочет прикрепить, нажать на кнопку "Экспортировать" и скопировать готовый iframe-код. После этого необходимо вставить этот код в специальную зону для HTML-разметки в CKEditor.
Предварительно разработчику необходимо сконфигурировать плагин CKEditor на стороне CMS и дать контент-менеджеры доступ к функционалу вставки HTML-разметки.

## Плюсы
- Не зависит от изменений домена.

## Минусы
- Небезопасно открывать доступ обычному пользователю для вставки HTML (можно вставить любой HTML код, а не только iframe).
