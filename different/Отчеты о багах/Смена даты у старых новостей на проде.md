# Смена даты у старых новостей на проде

**Дата инцидента:**  2026-09-03

## Описание
При деплое нового функционала для закрепления новостей произошел инцидент, при котором у всех старых новостей обновилась дата на текущую (2026-09-03).

Для добавления этого функционала было добавлено новое поле `isPinned` в новости. После добавления этого поля у всех старых новостей в базе данных в качестве значения был проставлен `null`. Но для корректной сортировки новостей значение должно быть либо `false`, либо `true`. Для того чтобы проставить в качестве дефолтного значения `false` всем старым новостям, был написан скрипт, который брал все новости с `isPinned=null` и обновлял им значение на `false`.

```js
const newsList = await strapi.db.query('api::news-collection.news-collection')
    .findMany({
      select: [
        'id',
        'isPinned'
      ]
    });

  for (const news of newsList) {
    if (news.isPinned === null) {
      await strapi.db.query('api::news-collection.news-collection').update({
        where: {
          id: news.id
        },
        data: {
          isPinned: false
        }
      });
    }
  }
```

Этот код бы хорошо сработал, если бы у нас не было кастомного кода для lifecycles, в котором содержится логика для автоматического проставления сегодняшней даты, если она не была проставлена вручную.

Не было учтено, что входящие параметры в `beforeCreate` и `beforeUpdate` — это параметры из request body запроса, а в скрипте для установки дефолтного значения `isPinned` были переданы только два параметра `id` и `isPinned`. Поэтому в `beforeUpdate` параметр `date` не приходил и срабатывала установка текущей даты, что и привело к обновлению дат в старых новостях.

```js
import slugify from "slugify";

module.exports = {
  beforeCreate({ params }) {
    const { data } = params;

    generateSlug(data)
  },

  beforeUpdate({ params }) {
    const { data } = params;

    generateSlug(data)
  },
}

function generateSlug(data: any) {
  if (!data.date) {
    data.date = new Date();
  }

  if (data.title) {
    let slug = slugify(data.title, {
      lower: true,
      strict: true
    });

    if (typeof data.date === 'string') {
      const splitDate = data.date.split('T')[0].split('-');

      data.slug = `${splitDate[0]}/${splitDate[1]}/${splitDate[2]}/${slug}`;
    } else {
      const splitDate = data.date.toISOString().split('T')[0].split('-');

      data.slug = `${splitDate[0]}/${splitDate[1]}/${splitDate[2]}/${slug}`;
    }
  }
}
```

## Фикс кода
В этом случае в `beforeUpdate` придут все параметры новости, в том числе и `date`.

```js
  await strapi.db.query('api::news-collection.news-collection').updateMany({
    where: {
      isPinned: null
    },
    data: {
      isPinned: false
    }
  });
```
