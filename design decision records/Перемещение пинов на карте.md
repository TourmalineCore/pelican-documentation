# Перемещение пинов на карте

## Статус
Предложенный (2026-11-3)

## Контекст
Сотрудники зоопарка должны иметь возможность управлять местоположением пинов животных на интерактивной карте, чтобы поддерживать ее в актуальном состоянии. Перемещать пины нужно в случаях, когда животное меняет вольер (например, со сменой сезона, при ремонте вольера или по медицинским показаниям).

## Решение
Слой с вольерами, сделанными через полигоны, будет подготовлен в программе QGIS и отрисован поверх других слоев подложки (например, газоны). В режиме редактирования, который будет доступен администратору, пины животных будут выделяться зажатием мышью или тачпадом и перетаскиванием пина на нужный вольер. Таким образом, будет определяться координата животного на карте, которую можно будет сохранить по клику на соответствующую кнопку. Сохраненные координаты будут записываться в базу данных и использоваться при отображении карты для всех пользователей.

## Альтернативы
Предусмотерть в админской панели Strapi возможность создать список вольером (точек на карте с координатами) и прикреплять каждое животное к нужному вольеру через админку. 

### Плюсы:
- Необходимый функционал списков и связывания сущностей поставляется вместе со Strapi, нет необходимости писать его самому. 
- Не требуется разрабатывать режим редактирования на клиенте — управление происходит через стандартный интерфейс Strapi.

### Минусы:
- Администратор работает с координатами без наглядного отображения карты, это менее удобно и повышает риск ошибки.
- Потребуется дополнительный код для рендеринга вольеров и пинов на карте на основе данных из Strapi.

## Последствия
- Потребуется реализовать режим редактирования карты, доступный только пользователям с ролью администратора.
- Необходимо добавить в модель данных животных поля для хранения координат (широта, долгота).
- На UI потребуется реализовать механизм drag-and-drop пинов и проверять попадают ли они в границы полигона вольера.
- Необходимо обеспечить сохранение изменённых координат в базу и их последующее отображение для всех пользователей.
- Потребуется подготовить слой вольеров в QGIS и обеспечить его корректное наложение на подложку карты.

## Плюсы
- Интуитивно понятный интерфейс drag-and-drop.
- Визуально сотрудник сразу видит куда он перемещает пин и попадает ли в границы вольера.
- Не нужно отдельно валидировать попадания пина в вольер.
- Нет нужно переключаться между разными системами (Strapi и карта), всё делается в одном интерфейсе.

## Минусы
- Необходимый функционал нужно будет разработать самостоятельно.
- Потребуется поддерживать слой вольеров в QGIS в актуальном состоянии при изменении планировки зоопарка.
