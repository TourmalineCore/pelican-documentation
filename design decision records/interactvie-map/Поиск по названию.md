# Поиск по названию

## Статус
Предложено (05-11-2026)

## Контекст
На интерактивной карте зоопарка много объектов без подписей, и для быстрого ориентирования по иконкам нужны условные обозначения или другая система ориентирования по карте, которая позволит посетителям быстро находить интересующие их объекты, не изучая всю территорию самостоятельно. Например, пользователю нужно найти туалет, вольер конкретного животного,  кафе, и т.д.

## Решение
Реализовать гибкий семантический поиск объектов на карте по названию с использованием ИИ.
Посетитель сможет вводить название интересующего его объекта в поисковую строку. Система будет обрабатывать запрос и  находить соответствующий объект среди представленных на карте.
После выбора найденного объекта карта должна отображать его расположение, чтобы посетитель мог быстро сориентироваться и определить, куда ему необходимо направиться, при помощи центрирования карты/зума/подсветки/открытия карточки объекта.
Использование ИИ рассматривается как способ сделать поиск более гибким и удобным для посетителей, не ограничивая их взаимодействие с картой только просмотром условных обозначений или заранее сформированного списка объектов.

## Альтернативы
1. Список инфраструктуры и вольеров.
Размещение отдельного списка всех объектов, представленных на карте. Посетитель сможет выбрать нужный объект из списка и перейти к его расположению на карте.

### Плюсы
- Посетитель получает полный перечень объектов, доступных для поиска.
- Реализация не требует использования дополнительных технологий и новой логики обработки поисковых запросов.

### Минусы
- При большом количестве объектов поиск нужного элемента в списке может занимать много времени.
- Для удобства использования потребуется разделить объекты на категории или предусмотреть дополнительную структуру списка.
- Длинный список может перегружать интерфейс карты и затруднять взаимодействие с ней.

2. Легенда обозначений. 
Каждому типу объекта будет соответствовать определенная иконка или графическое обозначение.

### Плюсы
- Помогает разобраться в значениях используемых иконок без необходимости открывать карточки объектов.
- Не требует разработки отдельного механизма поиска.

### Минусы
- Легенда объясняет значение обозначений, но не помогает найти конкретный объект среди множества аналогичных. Например, посетитель сможет определить, как обозначены туалеты, но ему все равно придется самостоятельно искать ближайший или нужный туалет на карте.
- При большом количестве типов объектов легенда может занимать значительную часть интерфейса.
- Посетителю необходимо самостоятельно сопоставлять обозначения в легенде с объектами на карте.

## Последствия
- Потребуется разработать поисковую строку и интерфейс отображения результатов поиска.
- Потребуется реализовать механизм семантической обработки поисковых запросов с использованием ИИ.
- Потребуется предусмотреть связь между результатами поиска и объектами на карте, чтобы при выборе найденного объекта карта могла отобразить его расположение.
- Потребуется подготовить и структурировать данные об объектах, чтобы система могла использовать их для обработки запросов.
- Потребуется предусмотреть возможность обновления поисковых данных при добавлении новых объектов или изменении существующих.
- Потребуется определить, как система будет обрабатывать запросы, по которым не удалось найти подходящий объект, и сообщать об этом посетителю.

## Плюсы
- Поиск позволяет быстрее находить интересующие объекты, не изучая всю территорию зоопарка самостоятельно.
- Использование ИИ может сделать взаимодействие с поиском более гибким по сравнению с обычным поиском по точному совпадению названия.
- Поиск позволяет сохранить основной интерфейс карты свободным от дополнительных подписей и элементов, поскольку посетитель сможет находить объекты через отдельную поисковую строку.
- Система может масштабироваться по мере добавления новых объектов инфраструктуры и вольеров без необходимости существенно менять структуру интерфейса.	

## Минусы
- Реализация поиска с использованием ИИ может потребовать дополнительных ресурсов и времени на разработку по сравнению с обычным поиском по названию.
- ИИ может ошибаться и снижать доверие.
- Зависимость от внешнего провайдера.
- Задержки при плохом интернете, например при поиске с мобильного устройства.
